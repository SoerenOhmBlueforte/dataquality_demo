# Beschreibung
Die Demo soll drei unterschiedliche superpowers vorstellen. Brainstorming, writing-plans und subagent-driven-development. Dafür werden drei Prompts abgesetzt.

# Prompt 1: Brainstorming
Ich möchte ein kleines Python CLI-Tool bauen, das CSV-Dateien auf Datenqualitätsprobleme prüft. 
Ziel ist eine kurze Demo. Bitte nutze Superpowers Brainstorming, halte den Scope sehr klein und schlage ein Design vor. Liefere für das Design direkt eine csv-Datei mit Beispieldaten, die Datenqualitätsprobleme enthalten, die das Tool lösen kann.

# Prompt 2: Plan erstellen
Das Design passt. Erstelle daraus einen möglichst kleinen Implementation Plan mit 2 bis 3 Tasks. Ziel ist, dass Tool am Ende in einem Test nutzen zu können.

# Prompt 3: Subagent-Driven Development
Setze den Plan mit subagent-driven-development um. Halte den Scope strikt klein. Bei Unklarheiten oder Klärungsbedarf schlage eine passende Variante vor und implementiere sie. Teile mir am Ende mit, ob du eigene Empfehlungen implementieren musstest und an welcher Stelle. 
Erstelle und nutze einen eigenen Feature-Branch im Git-Repo. Validiere und merge ihn zum Abschluss der Implementierung, sofern keine Fehler oder Bedenken vorliegen.
